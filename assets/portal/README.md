# Player portal tile photos

Drop photos here and they appear on the player portal's home tiles, faded into the tile.
Use photos you have the rights to: your own event photos, or licensed stock.
Don't use pictures of professional players or clubs without permission.

| File name (jpg, png or webp) | Tile        |
|------------------------------|-------------|
| `padel`                      | Padel       |
| `futsal`                     | Futsal      |
| `football`                   | Football    |
| `live`                       | Live now / Next match |
| `rankings`                   | Rankings    |
| `spectator`                  | Spectator   |

Landscape, about 1200×800, under 400 KB. The subject should sit on the right half;
the left side is covered by the tile's title.
